# V2.8.1 规划：会话强绑定修复 + 新建会话交互优化（小版本）

> 基线：v2.8.0（三大能力域对标优化）
> 立项：2026-11-17
> 需求来源：① 派生子会话删除父会话后子会话依然存活（数据层）+ 树形展示不正确（展示层）；② 新建会话交互对标 OpenClaw（点击新建不入列表，未对话切换自动丢弃，对话后才入列表并显示默认名）
> 复核结论（2026-11-17 对标）：A3 Hooks/automations 与 streamable HTTP 传输**不纳入本版**（无用户需求触发且属大特性；A3 建议 V2.9.0 评估、streamable HTTP 为 R6 观察项）——见 V2.8.0-PLAN 决策记录

## R1 派生子会话强绑定（数据层 + 展示层）

| 任务 | 内容 | 验收标准 |
|---|---|---|
| T1.1 级联删除 | `ConversationService.deleteSession` 删除父会话前级联删除其全部子会话（消息 + 会话行；一层树子会话无子级，单层遍历即可） | 删除父会话后子会话与子消息不再存活 |
| T1.2 树形展示核对 | 会话列表树形分组（child class + child-tag + 排序把子会话排父旁）代码核实 | 级联修复后无孤儿会话，展示自然正确 |

## R2 新建会话交互优化（OpenClaw 式）

| 任务 | 内容 | 验收标准 |
|---|---|---|
| T2.1 pending 会话态 | 新建会话改为本地 pending（不调创建接口、不入库、不出现在列表）；会话区显示默认名 New Session | 点击新建后列表无新增行 |
| T2.2 惰性创建收敛 | 首条消息发送时真实创建会话（fresh create，不复用已有活跃会话）+ 设置会话名 New Session；切换其他会话时 pending 静默丢弃 | 对话后会话入列表且名为 New Session；未对话切换则无残留 |
