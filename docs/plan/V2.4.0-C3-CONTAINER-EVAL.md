# V2.4.0 C3 决策：容器级沙箱（评估结论）

> 状态：评估完成（2026-11-02），**实施延后**
> 依据：本机取证 + 威胁模型对照
> 决策人：开发侧（依据 ROADMAP V2.4.0 C3 授权「先评估后决定」）

## 一、评估范围

评估是否在本版引入容器级沙箱（Docker / gVisor / Kata），替代或叠加现有进程级沙箱。

## 二、本机取证（决定"能不能做"）

| 项 | 结果 |
|---|---|
| `docker --version` | **不可用**（本机 Docker 引擎已损坏） |
| `docker info` | 引擎不可达 |
| `podman` | 不可用 |
| `nerdctl` | 不可用 |

**结论：本机无法构建/运行/实测任何容器级沙箱。** 任何"容器级已实现"的声称都无法实证，只能停留在纸面。

## 三、现有进程级沙箱能力盘点（决定"还需不需要"）

| 能力 | 实现证据 | 状态 |
|---|---|---|
| 进程隔离（独立子 JVM） | `ProcessBuilder` + `javaBin()` | ✅ |
| 超时熔断 + 强杀 | `proc.waitFor(timeoutMs)` + `destroyForcibly()`（SandboxRunner L195/L197） | ✅ |
| 内存上限 | `-Xmx` 可配（默认 256m） | ✅ |
| 极简 worker | 无 Spring / 无密钥 / 无 DB（仅 ScriptEngine） | ✅ |
| 表达式白名单收敛（B3） | `validateExpression` 双路径同源 | ✅ |
| 结果长度上限 | `maxResultChars` 截断 | ✅ |
| 审计留档 | `[Sandbox] 调用留档`（工具名/耗时/退出码/超时） | ✅ |
| traceId 父子透传 | 协议三段 + MDC | ✅ |

## 四、威胁模型对照（容器级的真实增量）

| 威胁 | 进程级现状 | 容器级增量 | 判定 |
|---|---|---|---|
| 死循环 / CPU 打满 | 超时强杀已覆盖 | cgroup CPU 上限更精细 | 增量小 |
| 内存暴涨 / OOM | `-Xmx` 已覆盖 | cgroup 内存硬限更稳 | 增量小 |
| `Java.type` 逃逸执行命令 | 表达式白名单已阻断（B3 实测） | 白名单才是主防线 | 无增量 |
| **读写宿主文件系统** | **未限制**（子进程继承宿主 FS 权限） | 只读挂载 / 独立 rootfs | **实质增量** |
| **访问内网 / 外呼** | **未限制**（子进程可自由出网） | 网络隔离 / no-network | **实质增量** |
| 污染宿主进程 / 端口 | 子进程独立，已隔离 | — | 无增量 |
| **逃逸至宿主内核** | 无内核隔离（共享内核） | 命名空间 + gVisor 更强 | **实质增量** |

## 五、成本项

- 当前 pom **无**任何容器编排依赖（docker-java / testcontainers 均无）
- 需新增：镜像构建与分发、运行时编排、资源限额策略、容器清理、CI 适配
- 运维负担：镜像版本管理、漏洞扫描、宿主机守护进程强依赖

## 六、决策

**容器级沙箱：评估完成，实施延后（不进 V2.4.0）。**

理由：
1. 本机无任何可用容器运行时 → 无法实证，做了也是"纸面能力"
2. 进程级已覆盖 CPU / 内存 / 逃逸执行三类主要风险——这正是本项目当前真实面临的威胁
3. 三项实质增量（FS 隔离 / 网络隔离 / 内核隔离）对应的是"执行不可信第三方代码"场景，而当前沙箱只跑**受白名单约束的表达式**，不是通用代码

**触发条件**（满足任一即重启本议题）：
- 需要执行**不可信第三方代码**（如用户自定义脚本、外源插件逻辑）
- 出现**多租户隔离**要求（不同租户代码需互不可见）
- 部署环境提供可用容器运行时且接受相应运维成本

## 七、替代方案（本版已采纳）

把"文件系统与网络隔离"的缺口，在进程级沙箱内用低成本方式部分补上：

| 缺口 | 进程级替代 | 状态 |
|---|---|---|
| 外呼失控 | 沙箱 worker 不加载任何网络客户端类；表达式白名单排除外呼语法 | 已由 B3 覆盖 |
| 文件系统写入 | worker 仅 `System.out` 输出结果，不提供文件写 API | 已由设计约束覆盖 |

即：**当前威胁面（受限表达式求值）已被进程级 + 白名单完整覆盖**，容器级的增量收益在当前场景下不成立。
